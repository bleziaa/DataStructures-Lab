# DataStructures Lab

Laboratorio visual e interactivo para estudiar siete estructuras de datos mediante nodos animados.

## Tecnologías
- Java 17
- JavaFX 21
- Maven
- JUnit 5

## Estructuras contempladas
1. Arreglos
2. Matrices
3. Listas enlazadas
4. Pilas (LIFO)
5. Colas (FIFO)
6. Árboles binarios de búsqueda
7. Grafos (BFS y DFS)

## Estado actual
**Etapa 1 — Base del proyecto e interfaz inicial.**

La primera pantalla incluye navegación entre los siete módulos y una demostración inicial de nodos circulares animados para insertar, eliminar y buscar valores. Las estructuras específicas y sus operaciones completas se implementarán módulo por módulo; esta pantalla inicial no representa todavía la entrega completa.

## Ejecutar
Se requiere JDK 17 y Maven 3.9 o superior.

```bash
mvn clean javafx:run
```

## Diseño
Tema oscuro con acentos morados y texto claro. Las animaciones se realizan con JavaFX Transitions.
